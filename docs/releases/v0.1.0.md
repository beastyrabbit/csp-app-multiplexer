CSP Mux 0.1.0 is the first public release of a small Windows proxy for Clip Studio
Paint's Companion Mode. Scan CSP's QR code once, then connect multiple companion apps
through the replacement QR generated by CSP Mux.

## Highlights

- Share one CSP Companion Mode session with up to eight apps.
- Keep connections on this computer or expose them only on a selected private IPv4
  address for phones and tablets on the same network.
- Hide the proxy QR after pairing without interrupting connected clients.
- Continue running from the Windows notification area when the main window is closed.
- Let CSP Palette Companion discover a local proxy session automatically.
- Recover cleanly when CSP disconnects or a companion app reconnects.
- Protect the proxy from slow clients with bounded per-client message queues.
- Target the latest available .NET platform: .NET 11 Preview 6 at release time.

## Before you install

This is a proof-of-concept release for Windows 10 and 11, x64. It has been verified with
CSP PRO 4.0.10 using the German interface and with CSP Palette Companion. Other Companion
Mode clients, sustained high client loads, and future CSP protocol changes have not yet
been broadly tested.

The executables are currently unsigned. Windows or antivirus software may therefore show
a warning; checksums are included below so the downloads can be verified.

This release intentionally tracks the newest .NET preview rather than the LTS channel.
The framework-dependent download requires the latest .NET 11 Desktop Runtime preview;
the standalone download includes the required runtime.
